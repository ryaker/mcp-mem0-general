# Mem0 MCP Server v0.1.0

## Desktop Extension Release

### Installation Instructions
1. Download the `mem0-mcp-server-0.1.0.dxt` file from the GitHub Release (NOT from the repository files)
2. Open Claude Desktop
3. Go to Extensions → Install from File
4. Select the downloaded .dxt file
5. Enter your Mem0 API key when prompted

### Features
- Full Mem0 memory management integration
- Support for all memory types (facts, preferences, goals, procedures)
- Intelligent caching for improved performance
- Easy configuration through Claude Desktop
- Cross-platform support (macOS, Windows, Linux)

### Important Notes
⚠️ **Download from GitHub Release Only**: Do not download the DXT file from the repository's main branch view. GitHub modifies binary files when served through the web interface, which corrupts the DXT package. Always use the official release asset.

### What's Fixed
- Rebuilt DXT package with proper compression
- Fixed "invalid zip data" error when installing
- Ensured compatibility with Claude Desktop's extension system

### Requirements
- Claude Desktop (latest version)
- Mem0 API key (get one at https://mem0.ai)
